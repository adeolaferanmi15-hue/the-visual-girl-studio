# The Visual Girl — AI Creative Studio

A responsive portfolio site using the brand palette:
- Blue: #C4DAE8
- Butter: #FEEFB8
- Chocopie: #432F2E

## Add the portfolio assets

Download and extract the complete website bundle from the ChatGPT conversation. In this repository, choose **Add file → Upload files**, then upload the bundle's `index.html` and the complete `assets/` folder. Keep the subfolder structure intact and commit to `main`. This replaces the starter page and adds the optimised images, video posters and videos.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then Save.

The expected site address is:

https://adeolaferanmi15-hue.github.io/the-visual-girl-studio/

The original `the-visual-girl-portfolio` repository is separate and is not changed by this project.
